01収集・処理する情報

アンダーハッチは、独自の会員登録なしでご利用いただけます。ただし、ランキング・対戦サーバーの記録、広告、アプリ内購入、アプリのアップデート・時刻確認およびお問い合わせ機能を提供するため、以下の情報が処理される場合があります。

1) Google AdMob 広告

本アプリは Google AdMob を利用してリワード広告のみを提供します。リワード広告は、利用者が緊急修理・報酬2倍などのボタンを自ら押したときにのみ再生され、バナー広告やインタースティシャル広告は表示しません。広告の配信にあたり、Google および Google と提携する広告ネットワークは、以下の情報を自動的に収集または処理することがあります。

  • 広告識別子 — Android 広告 ID、iOS 広告識別子（IDFA）。IDFA は、利用者が下記のトラッキング許可リクエストに同意した場合にのみ利用されます。
  • IP アドレスおよび IP アドレスに基づくおおよその位置情報
  • 端末の種類、機種、OS および言語設定
  • アプリのバージョンおよび広告 SDK の情報
  • 広告の表示、クリック、視聴完了および報酬付与の有無
  • アプリの起動および広告とのやり取りに関する情報
  • 広告不正の防止およびセキュリティに必要な技術情報
  • エラー・診断・パフォーマンスに関する情報

これらの情報は、広告の配信、広告表示頻度の調整、パーソナライズド広告または非パーソナライズド広告の提供、広告効果の測定、不正広告の防止およびサービス改善の目的で処理されることがあります。

広告内容の制限 — 本アプリは、すべての利用者に対して広告コンテンツのレーティングを PG（保護者の指導）以下に制限しています。成人向け・性的な広告（T・MA レーティング）はリクエストしません。

iOS のトラッキング許可リクエスト（App Tracking Transparency） — iOS では、アプリの初回起動時に Apple のトラッキング許可リクエストが表示されます。許可しない場合、広告識別子（IDFA）は提供されず、広告は引き続き表示されますが、パーソナライズされていない広告となります。この選択は、iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」でいつでも変更できます。

欧州経済領域（EEA）・英国・スイスの利用者 — これらの地域の利用者には、アプリの初回起動時に Google の同意管理プラットフォーム（UMP）を通じてパーソナライズド広告への同意の有無をお尋ねします。同意しなくてもゲームはご利用いただけます。ただし、同意の状況や Google の判断によっては、広告が制限されたり表示されなかったりすることがあり、その場合は広告の視聴によって得られる報酬を受け取れないことがあります。同意の有無は、アプリの「設定」→「広告のプライバシー設定」でいつでも選び直すことができます。

利用者の年齢、地域、同意状況および端末の設定によっては、パーソナライズド広告が表示されることがあります。利用者は、Google マイ アド センター、Android 端末の広告設定または iPhone のトラッキング設定から、パーソナライズド広告をオフにしたり、広告識別子をリセット・削除したりできます。

端末や Android のバージョンによってメニュー名は異なる場合がありますが、一般的には以下の場所で設定できます。

  • Android の「設定」→「Google」→「広告」（または「広告のプライバシー」）
  • 広告のカスタマイズをオフにする
  • 広告 ID をリセットまたは削除する
  • iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」→ このアプリのトラッキング許可をオフにする
  • Google マイ アド センター
  • Google プライバシーポリシー

広告のカスタマイズをオフにしても広告自体は引き続き表示されますが、利用者の興味・関心に基づかない非パーソナライズド広告が表示されることがあります。

2) アプリ内購入（Google Play · Apple App Store）

本アプリでは、Android の Google Play 決済システムまたは iOS の Apple App Store アプリ内購入を通じて、ダイヤ、パス、パッケージなどのデジタル商品を購入できます。

決済および支払い方法の管理は Google Play または Apple が直接行います。開発者は、クレジットカード番号、口座番号、決済パスワードなどの支払い方法に関する情報にアクセスしたり、保存したりすることはありません。

購入の確認、商品の付与、購入の復元、重複付与の防止、返金処理および不正取引の防止のため、以下の最小限の決済情報が処理されることがあります。

  • 購入した商品の ID
  • 注文番号または取引 ID
  • 購入トークン
  • 購入日時
  • 決済および購入の状態
  • 購入のキャンセル・返金・取り消しの状態
  • 商品の付与および消費処理の有無

購入確認サーバー — 購入が正常かどうかを確認するため、本アプリは購入直後に、開発者が運営する確認サーバー（Google Cloud Functions、ソウルリージョン）へ以下の情報を送信します。

  • 購入トークン（Android）または Apple が署名した取引情報（iOS）
  • 商品 ID、商品の種類、アプリのパッケージ名・バンドル ID、プラットフォーム（Android/iOS）

確認サーバーは、これらの情報をもとに Google Play 開発者 API への照会または Apple のレシート署名検証を行い、結果（付与の可否）をアプリに返します。購入トークンおよび Apple の署名付き取引情報（レシート）の原文は保存しません。

ただし、同じ購入が重複して付与されたり、別のアカウントで再度使用されたりすることを防ぐため、確認サーバーは購入ごとに以下の情報を購入記録としてサーバーに保存します。

  • 購入識別値（購入トークンまたは取引番号をハッシュ値に変換したもの。原文を復元することはできません）
  • 匿名アカウント番号
  • 商品 ID
  • 購入日時
  • テスト決済かどうか
  • 記録日時

エラーが発生した場合は、原因の特定のために商品 ID とエラーの種類がサーバーの記録に残ることがありますが、購入トークンおよび取引情報は記録しません。これとは別に、端末内にも付与の記録（重複付与を防ぐための購入台帳）が保存されます。

3) ゲーム進行データ

ゲームの進行に伴い、以下のデータが生成されることがあります。

  • 艦長名（利用者が自ら入力するゲーム内ニックネーム）
  • コイン・ダイヤ・鋼板・部品などのゲーム内通貨および所持アイテム
  • 砲塔および艦船の強化情報
  • ステージクリア記録および地獄難易度の記録
  • パスの進行状況および報酬受け取りの記録
  • 巡回報酬および毎日のプレゼント受け取りの記録
  • ゲームの設定情報

ゲーム進行データは端末のローカルストレージに保存されます。現在、アカウント連携やクラウドバックアップの機能はないため、端末を変更したり、アプリまたはアプリデータを削除したりすると、記録を復元できないことがあります。ランキング・対戦機能に使われる一部の記録のみが、下記4)のサーバーに保存されます。

艦長名はゲーム内で使用されるニックネームで、端末内に保存されます。ただし、ランキング・対戦機能を利用すると、下記4)のサーバーにも保存され、他の利用者に表示されます。運営の基準に合わない名前は、自動的に変更されたり、開発者が変更または初期化したりすることがあります。艦長名には、本名や連絡先などの個人情報を入力しないことをおすすめします。

4) ランキング・対戦サーバー（Google Firebase）

本アプリは、ランキング戦、無限戦、対戦機能の記録と順位を管理するため、開発者が運営するサーバー（Google Firebase：匿名認証、Cloud Firestore、Cloud Functions）を利用します。この機能を利用するために別途ログインや会員登録をする必要はなく、アプリが利用者に意識させることなく、氏名や連絡先を用いない匿名アカウントを自動的に作成して使用します。この過程で、サーバーに以下の情報が保存されます。

  • 匿名アカウント番号（Firebase 匿名認証が付与する識別番号）と、アプリが端末上で作成したゲーム用 ID
  • 艦長名（利用者が自ら入力するニックネーム、最大12文字）
  • ステージクリア記録、受けたダメージ、クリア時間、挑戦回数などのランキング戦・無限戦の記録
  • 対戦トロフィー、戦闘力、対戦に使われる陣形（武器・強化段階）の配置とスキン情報
  • 1日あたりの対戦回数、アリーナポイント、週間報酬の付与の有無など、サーバーで管理される機能の利用記録
  • 称号、階級、プロフィール枠など、ランキング・対戦に表示される装飾情報
  • スキン欠片の所持数と、スキン欠片の獲得に関する1日あたりのプレイ数
  • 対戦レポート（直近30戦の勝敗、トロフィーの増減、自分と相手の艦長名・戦闘力・ダメージなどの戦闘結果）
  • メールボックスの受け取り記録、アリーナショップの購入記録、ランキング戦・無限戦の開始記録
  • 最終接続日時
  • 購入確認の記録（上記2) アプリ内購入の購入確認サーバーの項目を参照）
  • サーバーへのリクエスト時に送信される IP アドレスなどの通信記録（Google が処理するものであり、開発者が利用者の識別に使用することはありません）

公開範囲 — 艦長名、ステージ・トロフィー・戦闘力および順位の情報は、ランキングで他の利用者に表示されます。対戦では、利用者の艦長名、トロフィー、戦闘力、陣形の配置、スキン、階級・称号・プロフィール枠が他の利用者の対戦相手の情報として使用され、相手に表示されることがあります。対戦レポートには対戦相手の艦長名と戦闘情報も併せて保存され、名前を変更しても、すでに保存された対戦レポート内の以前の名前は変更されないことがあります。匿名アカウント番号とゲーム用 ID はアプリの画面には表示されませんが、ランキングのデータ構造上、サーバーの文書に含まれています。利用者の本名・連絡先・決済情報・広告識別子は、このサーバーには保存しません。

ランキング・対戦の記録はサーバーが管理しており、アプリがサーバーに直接書き込めないよう制限されています。週間ランキングの過去の記録は保存され、今週・先週の順位として閲覧できます。アプリを削除して再インストールすると新しい匿名アカウントが作成され、ランキングに新しい記録が作られます。以前のアカウントの記録は、削除をご請求いただくまで残ることがあります。対戦レポートは利用者あたり直近30戦分のみが保持され、それ以外の記録は、別途削除をご請求いただくまでサーバーに保管されることがあります。

5) アプリのアップデート・時刻確認

本アプリは起動時に、ゲーム内容（コード・画像）の新しいアップデートがあるかどうかを確認し、ある場合はダウンロードして適用します。この機能には Expo（650 Industries, Inc.）のアップデートサーバーを利用しており、その過程で以下の情報が送信されます。

  • IP アドレス
  • プラットフォーム（Android/iOS）、アプリのバージョンおよび現在適用されているアップデートの識別子

これらの情報は、適切なアップデートを配信するためにのみ使用され、開発者が利用者の識別に使用することはありません。

  • Expo プライバシーポリシー

ストアの新バージョン確認 — 本アプリは、ストア（Google Play または Apple App Store）に新しいバージョンがあるかどうかを確認するため、該当ストアに照会することがあり、その過程でアプリのバージョン、パッケージ名・バンドル ID および IP アドレスが該当ストアに送信されることがあります。

サーバー時刻の確認 — エネルギー、1日の挑戦回数、週間報酬など、サーバー時刻を基準とする機能のために、本アプリは Google のサーバー（www.google.com）にリクエストを送り、時刻情報のみを受け取ります。このリクエストには利用者の IP アドレスが送信されますが、開発者がこの情報を保存したり、利用者の識別に使用したりすることはありません。

6) 情報の収集方法

個人情報および利用情報は、以下の方法で収集・処理されることがあります。

  • ゲームの起動およびプレイの過程
  • ランキング戦・無限戦・対戦の記録の送信および順位の照会の過程（匿名アカウントの自動作成を含む）
  • Google Play または Apple App Store のアプリ内購入および購入確認の過程
  • Google AdMob 広告のリクエスト・表示・クリック・視聴の過程
  • iOS のトラッキング許可リクエストおよび EEA・英国・スイスにおける広告同意の過程
  • アプリ起動時のアップデート確認、ストアの新バージョン確認およびサーバー時刻の確認の過程
  • アプリと Google・Apple のサービスとの間の自動通信
  • お問い合わせ、またはエラー・返金に関するお問い合わせの過程

お問い合わせ — メールボックスの「お問い合わせ」を押すと利用者のメールアプリが開き、本文にゲーム用 ID、アプリのバージョン、端末情報があらかじめ入力されます。利用者がメールを自ら送信した場合にのみ開発者に届き、送信前に内容を削除または修正することができます。

02情報の利用目的

開発者および本アプリに適用される外部サービスは、収集した情報を以下の目的で処理します。

  • ゲーム進行データの保存および利用
  • ランキング戦・無限戦・対戦の順位の集計と表示、対戦相手のマッチング、週間報酬の付与
  • 記録の改ざん防止および不正な利用の確認
  • リワード広告の提供
  • パーソナライズド広告または非パーソナライズド広告の提供
  • 広告効果の測定および広告表示頻度の調整
  • 広告不正および不正な利用の防止
  • アプリ内購入の確認、商品の付与および購入の復元
  • 重複決済・不正決済の防止および返金処理
  • アプリのアップデート確認・適用、ストアの新バージョン確認およびサーバー時刻の確認（サーバー時刻を基準とする機能の正確な運営）
  • ゲームのエラー確認、サービスの安定性確保および利用環境の改善
  • 利用者からのお問い合わせおよび紛争への対応
  • 関連法令上の義務の履行

開発者は、収集した情報を上記の目的と関係のない用途に利用しません。利用目的を変更する場合は、関連法令に従い別途同意を得るか、必要な事項をお知らせします。
