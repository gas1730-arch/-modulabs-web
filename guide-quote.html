01📋 시작하기 (앱 실행 → 로그인)

가입 & 로그인

  • 이메일+비밀번호로 가입하거나, 구글 계정으로 바로 로그인할 수 있습니다.
  • 처음 로그인하면 개인정보처리방침 동의 화면이 한 번 나옵니다. 체크하고 "동의하고 시작하기"를 눌러야 앱을 쓸 수 있습니다.
  • 가입 후에는 사업자 정보(상호, 대표자, 사업자번호, 주소, 전화, 계좌)를 설정 화면에서 채워두면, 견적서/문서에 자동으로 들어갑니다.

로그인 없이 앱 둘러보기

  1. 로그인 화면에서 "로그인 없이 둘러보기"를 누르세요.
  2. 홈 화면의 달력은 자유롭게 살펴볼 수 있습니다.
  3. 견적서 작성이나 방문예약처럼 데이터를 저장해야 하는 기능을 누르면, 그 시점에 가입/로그인 화면으로 안내됩니다.

02🗓️ 홈 화면 (달력)

  • 달력에서 날짜를 탭하면 그날의 견적서·방문예약·일정이 아래 목록에 나타납니다.
  • 날짜 밑의 작은 점 색깔로 구분됩니다 — 파랑 = 견적서 / 초록 = 방문예약 / 주황 = 일정
  • 화면 맨 위 오른쪽엔 🔍(통합 검색), 📁(저장된 문서함), ⚙️(설정) 아이콘이 있습니다.
  • 맨 위 왼쪽엔 지금 상태가 뜹니다 — 프리미엄이면 "⭐ 며칠 남음", 아니면 "‹ 뒤로" 등.
  • 화면 하단 3개 버튼: 📝 견적서 작성 / 🏠 방문예약 / 📌 일정 추가

03📝 견적서 작성 (홈 → 📝 견적서 작성)

입력 순서

  1. 작업 날짜 / 고객명(필수) / 주소 / 전화번호를 입력합니다. 주소는 "검색" 버튼으로 실제 주소를 찾아 넣을 수 있습니다.
  2. 작업 항목 — 설정에서 정해둔 업종의 기본 항목을 탭해서 고르거나, 직접 입력해서 추가할 수 있습니다.
  3. 견적 금액을 숫자만 입력하고, 부가세 포함/별도 중 선택하면 공급가액·부가세·합계가 자동으로 계산되어 보여집니다.
  4. 필요하면 약속 시간과 알림(약속 전 5분~1일 전 중 선택)을 설정합니다.
  5. 사진 첨부 — 무료는 1장, 프리미엄은 5장까지 가능합니다. 카메라 촬영 또는 사진첩에서 선택.
  6. 맨 아래 저장하기를 눌러야 실제로 저장됩니다.
✋ 저장하기 전에 뒤로가기를 누르면 "입력한 내용이 사라져요" 확인창이 뜹니다. 실수로 나가서 작성한 내용을 잃어버리는 걸 막아줍니다.

04📦 이사·운송 업종 전용 기능

업종을 "이사·운송"으로 설정한 경우에만 나타나는 기능입니다.

📦 이사 물품 체크리스트

업종이 "이사·운송"이면 견적서 작성 화면에 이 버튼이 따로 생깁니다. 실제 이삿짐센터 견적서 양식을 본떠서 만들었습니다.

  • 탭 구성: 안방 / (+건너방 추가, 여러 개 가능) / 거실 / 주방 / 베란다·기타 / 옵션
  • 각 방마다 품목(장농, 침대, TV, 냉장고 등)을 +/− 로 개수만 체크하면 됩니다. 목록에 없는 품목은 "+ 품목 추가"로 이름을 직접 넣어서 추가할 수 있습니다.
  • 품목 이름을 탭하면 그 아래로 메모와, 필요하면 별도 금액(예: 에어컨 이전설치비)도 넣을 수 있습니다.
  • 옵션 탭: 사다리차·엘리베이터·계단작업·스카이·에어컨 이전설치 등을 켜면 금액/메모를 넣을 수 있고, 목록에 없으면 직접 옵션을 추가할 수도 있습니다.
  • 완료를 누르면 체크한 내용이 자동으로 작업 항목에 정리되어 들어가고, 옵션 금액은 견적 금액과 별도로 합산됩니다.
✋ 체크리스트 작성 중 취소하거나 뒤로가면 "지금 취소하면 사라져요" 확인창이 떠서 실수로 날리는 일이 없게 되어 있습니다.

계약금 / 잔금

견적 금액 아래 "계약금 (원, 선택)" 입력란이 있습니다. 나중에 고객이 계약하겠다고 연락 오면, 그 견적서를 수정으로 열어서 계약금만 입력하고 저장하면 잔금이 자동으로 계산됩니다.

05🏠 방문예약 (홈 → 🏠 방문예약)

정식 견적서를 쓰기 전, "일단 방문 약속만 잡아둔" 가벼운 기록입니다. 고객명·연락처·주소·예상 작업·예상 금액 정도만 간단히 남겨둡니다.

방문해서 실제 견적이 나오면, 상세보기에서 "📄 견적서로 전환"을 눌러 입력했던 내용을 그대로 견적서로 옮길 수 있습니다 (원래 방문예약은 삭제할지 물어봅니다).

06📌 일정 (홈 → 📌 일정 추가)

제목과 메모만 남기는 단순 메모 기능입니다. 견적/금액과 상관없는 개인 일정이나 참고사항 남길 때 씁니다.

07🔎 상세보기 화면 (달력에서 견적서·예약·일정 탭)

할 수 있는 것들

  • 제목 옆 "수정" / "삭제" 링크
  • 📞 전화 — 바로 전화 연결
  • 📩 안내 문자 발송 — 상황별 문구 7종(견적발송/방문확정/작업확정/전날 리마인더/당일 출발/완료/입금 안내) 중 골라 채우거나 직접 작성해서 문자 앱으로 보냅니다.
  • 👷 직원에게 작업 내용 공유 — 작업 정보(+대표 사진 1장)를 카카오톡 등으로 바로 공유합니다.
  • 🗺️ 카카오맵 길안내 — 주소로 바로 길찾기
  • 📄 견적서 PDF로 보기 (견적서인 경우) / 📄 견적서로 전환 (방문예약인 경우)

08🤝 직원 초대 및 연동 (설정 → 👥 직원 관리)

직원을 앱에 초대해서 견적서·방문예약·A/S 요청을 공유할 수 있게 만드는 방법입니다.

  1. 설정 → 👥 직원 관리로 들어갑니다.
  2. 직원의 이메일 주소를 입력하고 "초대 보내기"를 누릅니다.
  3. 직원이 자기 앱에서 "수락"을 누르면 자동으로 연동됩니다.
  4. 연동된 직원은 사장님이 공유해준 항목만 볼 수 있습니다. 전체 견적서나 매출 정보는 보이지 않습니다.

09🗂️ 직원 팀 관리 (여러 명일 때)

직원이 여러 명일 때는 팀으로 묶어두면, 매번 개별로 고르지 않고 팀 단위로 한 번에 공유할 수 있습니다.

  1. 설정 → 👥 직원 관리 → 직원 팀 관리 → "새 팀 만들기"를 누릅니다.
  2. 팀 이름을 짓고 팀원을 체크한 뒤 저장합니다.
  3. 직원 이름은 이메일 대신 알아보기 쉬운 이름(예: "김기사", "박팀장")으로 바꿔둘 수 있습니다.

10📤 직원에게 업무 공유하기

연동된 직원에게 견적서·방문예약·A/S 요청을 맡기는 방법입니다.

  1. 공유하려는 견적서·방문예약·A/S 요청의 상세화면을 엽니다.
  2. "직원에게 공유하기"를 누릅니다.
  3. 개별 직원 또는 팀을 선택합니다. 필요하면 지시사항을 함께 입력할 수 있습니다.
  4. "공유하기"를 누르면 해당 직원에게 알림이 발송됩니다.

11📬 공유 현황 확인하기

직원 입장 — 공유받은 업무 확인하기

  1. 알림이 오면 앱을 열어 설정 → 🔔 알림으로 들어갑니다.
  2. 공유받은 항목을 누르면 상세화면으로 바로 이동합니다.
  3. 확인 후 필요하면 사장님과 문자로 소통하거나 카카오맵으로 길안내를 받을 수 있습니다.

사장님 입장 — 직원 확인 여부 보기

  1. 설정 → 📬 공유 현황으로 들어갑니다.
  2. 내가 공유한 항목이 목록으로 보이고, 각 직원의 확인 여부(미확인/확인)가 표시됩니다.
  3. 항목을 누르면 어떤 견적서·A/S를 언제 공유했는지, 누가 봤는지 상세히 확인할 수 있습니다.

12🛠️ A/S 요청 등록 및 관리

이미 작업이 완료된 건에 대해 A/S 요청을 접수하고 처리 상태를 관리하는 방법입니다.

  1. A/S가 필요한 견적서 상세화면을 엽니다.
  2. "A/S 요청 등록"을 누르면 해당 견적서의 고객 정보가 자동으로 채워집니다.
  3. 증상과 방문 예정일을 입력하고 등록을 누릅니다.
  4. 등록된 A/S 요청은 접수 → 처리중 → 완료 순서로 상태를 바꿔가며 관리할 수 있습니다.
  5. 필요하면 상세화면에서 "직원에게 공유하기"로 담당 직원에게 넘길 수 있습니다.

13🖨️ 문서 출력 & 저장함 (설정 → 🖨️ 문서 출력)

4가지 서류 양식

  • 견적서 — 항상 무료·무제한. 이사·운송 업종은 물품 체크리스트를 썼다면 방/구역별 박스로 정리된 전용 양식이 자동 적용됩니다.
  • 세금계산서 / 간이영수증 / 거래명세서 — 무료 10건 소진 후에는 하루 1회까지 저장·공유 가능 (미리보기는 항상 무료).

이사 옵션(사다리차 등)이 있는 견적서는 네 양식 모두 "이사비용/사다리차/옵션명" 이런 식으로 항목별 금액이 나눠서 나옵니다. 거래명세서는 미리보기에서 "📦 이사 물품 내역 표시" 토글로 상세 내역을 켜고 끌 수 있습니다.

저장된 문서함 (📁)

미리보기에서 "💾 앱에 저장"한 문서들을 다시 볼 수 있는 곳입니다. 미리보기/공유/삭제가 가능합니다.

14📊 엑셀로 내보내기 (매출 통계 화면 · PDF 미리보기 화면)

  • 기간별 장부 (매출 통계 → 📊 엑셀로 내보내기): 이번 주 / 이번 달 / 올해 / 기간 직접 선택 중 골라서, 그 기간 견적서를 표 하나로 모아 엑셀 파일로 받습니다.
  • 개별 문서 내보내기 (PDF 미리보기 → 📊 엑셀로 내보내기): 방금 보고 있는 문서 하나를 엑셀로도 받을 수 있습니다.
  • 내보낸 파일은 "공유" 창이 뜨는데, 거기서 엑셀 앱(초록 아이콘)을 고르면 바로 열립니다. 카카오톡 등으로 바로 전송도 가능합니다.

15👥 고객 명부 (설정 → 👥 고객 명부)

지금까지 견적서를 작성한 고객들이 자동으로 목록에 모입니다. 고객을 탭하면 그 고객과의 견적 이력, 누적 금액, 전화·문자·길안내 버튼이 나옵니다.

고객 명부에서 빠르게 찾기

  1. 고객 명부 화면 상단의 검색창을 누릅니다.
  2. 고객명이나 전화번호를 입력하면 실시간으로 필터링되어 나타납니다.
  3. 검색된 고객을 누르면 바로 상세 이력 화면으로 이동합니다.

16📈 매출 통계 (설정 → 📊 매출 통계)

월별 / 주별 / 연도별로 매출을 그래프와 함께 확인할 수 있습니다. 항목을 탭하면 해당 기간의 달력으로 바로 이동합니다.

17🔍 통합 검색 (홈 화면 상단 🔍)

고객명·전화번호·주소·작업내용으로 견적서와 일정을 한 번에 검색할 수 있습니다.

18🔔 알림 확인하기

공유받은 업무, A/S 요청 등 앱에 도착한 알림을 확인하는 방법입니다.

  1. 설정 → 🔔 알림으로 들어갑니다.
  2. 알림 목록에서 확인하고 싶은 항목을 누르면 해당 상세화면으로 바로 이동합니다.
  3. 확인한 알림은 목록에서 자동으로 정리됩니다.

19⚙️ 설정 (홈 화면 상단 ⚙️)

이 화면에서 할 수 있는 것

  • 🏢 사업자 정보 — 상호/대표자/사업자번호/주소/전화/계좌. 문서에 자동으로 반영됩니다.
  • 🔧 대표 업종 설정 — 업종을 고르면 견적서 작성 시 그 업종에 맞는 기본 작업 항목 칩이 뜹니다. 종목을 직접 입력해서 등록해야 세금계산서 등에 찍히는 "종목"란에 반영됩니다.
  • 🖨️ 문서 출력 / 📁 저장된 문서 / 📊 매출 통계 바로가기
  • 데이터 현황 — 저장된 견적서 수, 고객 수, 전체 합계

20⭐ 무료 이용 & 프리미엄

기본 원칙

  • 가입 후 견적서+방문예약 합쳐서 평생 10건은 기간 제한 없이 프리미엄과 동일하게 전부 무제한 이용 가능합니다.
  • 10건을 다 쓰면, 광고를 보고 받는 포인트로 계속 견적서/방문예약을 만들 수 있습니다 — 하루 최대 10회 시청, 포인트는 그날 자정에 사라집니다.
  • 프리미엄 구독은 월 19,800원이고, 구독 중엔 모든 제한 없이 자유롭게 이용할 수 있습니다.
  • 이사·운송 업종이라면 통합 크레딧을 구매해서 이사 견적 요청 마켓플레이스 기능을 이용할 수 있습니다. 자세한 내용은 22. 이사 견적 요청 받기를 확인하세요.

21💬 자주 묻는 질문

사업자 정보를 안 채우면 어떻게 되나요?
견적서 작성이나 무료 이용에는 지장 없습니다. 다만 PDF 문서(공급자란)에 빈칸으로 나오니, 실제로 문서를 발급하시기 전에 설정에서 미리 채워두시는 걸 추천합니다.
이사·운송 업종을 골랐는데 체크리스트 버튼이 안 보여요.
설정 → 업종 선택 화면에서 드롭다운으로 "이사·운송"을 한 번 다시 탭해서 선택해주세요. 목록에서 고르기만 하고 저장 버튼을 따로 안 눌러도 탭하는 즉시 저장됩니다.
포인트가 갑자기 사라졌어요.
광고를 보고 받은 포인트는 그날 하루만 유효합니다. 자정이 지나면 그날 안 쓴 포인트는 소멸됩니다. 무료체험 10건(평생)과는 별개입니다.
계약금은 어디서 입력하나요?
이사·운송 견적서 작성 화면에서 견적 금액 아래에 "계약금 (원, 선택)"란이 있습니다. 나중에 다시 "수정"으로 들어와서 채워도 됩니다.
프리미엄 결제하면 광고가 안 뜨나요?
네. 광고는 프리미엄 전용 화면의 "광고 보고 포인트 받기" 버튼 하나뿐이라, 프리미엄 이용 중에는 그 버튼 자체가 아예 보이지 않습니다.
이사 견적 요청은 어떻게 열람하나요?
새 요청이 등록되면 활동지역이 일치하는 모든 이사업체에게 알림이 갑니다. 상세 내용(고객명, 연락처, 주소, 물품 목록, 사진)을 보려면 통합 크레딧을 사용해야 하며, 필요한 크레딧 수량은 열람 전에 화면에서 확인할 수 있습니다.

22📮 이사 견적 요청 받기 (통합 크레딧)

고객이 앱 밖에서(회원가입 없이) 이사 견적을 요청하면, 활동지역이 일치하는 이사업체 전체에게 새 요청이 도착했다는 알림이 갑니다. 다만 요청의 상세 내용(고객명, 연락처, 주소, 물품 목록, 사진)을 열람하려면 통합 크레딧을 사용해야 합니다.

크레딧으로 요청 열람하는 방법

  1. 설정 → ⭐ 무료 이용 & 프리미엄 화면에서 크레딧을 구매할 수 있습니다 (33,000원 / 55,000원 / 110,000원 상품, 구매 시 보너스 크레딧이 추가로 지급됩니다).
  2. 새 요청 목록에서 열람하고 싶은 요청을 선택하면, 차감되는 크레딧 수량이 화면에 먼저 표시됩니다. 필요한 크레딧 수량은 서비스 종류, 지역, 운영정책 등에 따라 다를 수 있습니다.
  3. 수량을 확인하고 열람을 진행하면 크레딧이 차감되며, 그 즉시 요청의 상세 내용을 볼 수 있습니다.
  4. 이미 크레딧을 사용해 열람한 요청을 고객이 단순히 수정하거나 재등록한 경우, 크레딧이 다시 차감되지 않을 수 있습니다.

새 요청 확인하고 응답하는 방법

  1. 내 활동지역에 새 이사 견적 요청이 등록되면 푸시 알림이 옵니다(예: "○○구 → ○○구 이사 요청이 도착했어요").
  2. 알림을 탭하면 요청 목록으로 이동합니다. 크레딧을 사용해 열람하면 바로 상세 내용을 확인할 수 있습니다.
  3. 상세 내용에는 고객명, 연락처, 출발지·도착지, 이사 희망일, 물품 체크리스트, 첨부 사진(있는 경우)이 표시됩니다.
  4. 고객에게 연락해 견적을 안내하고, 고객이 업체를 확정하면 그 사실이 앱에 표시됩니다.
🔒 크레딧이 없으면 새 요청 알림은 받지만, 상세 내용은 열람할 수 없습니다. 요청을 실제로 수주하려면 크레딧을 사용해 열람해야 합니다.
⚠️ 고객이 앱을 통해 알게 된 개인정보(연락처, 주소 등)는 견적 제공과 계약 목적으로만 사용해야 하며, 다른 목적으로 이용하거나 제3자에게 제공할 수 없습니다.
